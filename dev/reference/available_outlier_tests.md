# A character vector containing all the names of the currently supported outliers tests that can be called in the function [outlier_filter](https://calabrialab.github.io/ISAnalytics/dev/reference/outlier_filter.md).

A character vector containing all the names of the currently supported
outliers tests that can be called in the function
[outlier_filter](https://calabrialab.github.io/ISAnalytics/dev/reference/outlier_filter.md).

## Usage

``` r
available_outlier_tests()
```

## Value

A character vector

## Examples

``` r
available_outlier_tests()
#> [1] "outliers_by_pool_fragments"
```

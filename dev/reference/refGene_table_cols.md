# Required columns for refGene file.

Required columns for refGene file.

## Usage

``` r
refGene_table_cols()
```

## Value

Character vector of column names

## Examples

``` r
refGene_table_cols()
#>  [1] "name2"          "chrom"          "strand"         "min_txStart"   
#>  [5] "max_txEnd"      "minmax_TxLen"   "average_TxLen"  "name"          
#>  [9] "min_cdsStart"   "max_cdsEnd"     "minmax_CdsLen"  "average_CdsLen"
```
